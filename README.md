# CircuitApp — Редактор логических схем

Это графический редактор для создания и симуляции электрических и логических схем на Java (Swing).

## Возможности:
* Светодиоды, резисторы, выключатели и питание.
* Логические элементы: AND (И), OR (ИЛИ), NOT (НЕ).
* Симуляция протекания тока и сгорания светодиодов.
* Встроенные иконки и понятный интерфейс.

## Как запустить:
1. Перейдите в раздел **Releases** справа.
2. Скачайте файл `CircuitApp.jar`.
3. Запустите его двойным кликом (требуется установленная Java).

## Сборка из исходников:
```cmd
javac -encoding UTF-8 CircuitApp.java
jar cfm CircuitApp.jar manifest.txt *.class resources
